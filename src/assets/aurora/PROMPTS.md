# Aurora animation artwork

Generated using an AI image-generation tool and the supplied character reference. The reference is preserved in this asset directory. The final sprite layout and generation prompts are documented below.

## First generation prompt

Use case: identity-preserve. Asset type: production 4 by 4 sprite atlas for a Windows desktop companion named Aurora. Image 1 is the exact character reference. Generate one large square transparent PNG sprite sheet with EXACTLY 4 equal columns and 4 equal rows, sixteen separate full-body sprites, one sprite centered in each cell, generous transparent padding, no overlaps, no text, no labels, no grid lines. Preserve the reference's adult anime pixel-art woman identity: very long flowing pink/lavender hair, violet eyes, white and purple fitted magical suit with gold trim and heart-shaped pink gems, long white gloves, white thigh-high boots with purple/gold heels, same adult body proportions and face, same detailed crisp pixel style. Do NOT make her chibi or redesign her. Every frame same character scale, full body, identical foot baseline and consistent camera. Row 1 left to right: neutral idle standing eyes open; same idle eyes closed for blink; thoughtful with hand to chin; waiting with hands gently clasped. Row 2 left to right: coding at small floating purple laptop hands on keyboard pose A; exactly same coding pose B with fingers and hair slightly moved; browsing at same floating laptop with visible tiny magnifying-glass symbol and hand operating trackpad pose A; same browsing pose B slight hand and hair movement. Row 3 left to right: walking three-quarter view facing right left foot forward; matching walking frame right foot forward; climbing facing right both arms reaching above shoulder level one knee lifted; matching climbing pose alternate arm/knee lifted. Row 4 left to right: celebrating smiling raising one hand; matching celebration with both hands raised; concerned/error one hand behind head; matching concerned with subtle change. Transparent alpha backdrop across all gutters and cell margins, no scenery, no ground shadows, no extra characters. Precisely regular 4x4 atlas for direct CSS sprite animation.

## Final layout revision prompt

Use case: identity-preserve. Edit target Image 1 is an Aurora 4x4 sprite atlas. Image 2 is her identity reference. Correct only the layout of Image 1: preserve every pose and character identity, outfit, pink hair, pixel art; shrink each figure to fit COMPLETELY inside its own equal square cell with wide transparent margins. Output ONE square transparent atlas, exactly4 columns and4rows. Imagine a precise evenly spaced 4x4 grid, each cell equal. Entire head, hair, boots, laptop and raised hands must be present WITHIN EACH CELL, never touch the cell edges or overlap adjoining cells. Place each character at the center of its cell; leave minimum 12% padding on all four sides of each cell. All 16 figures must be complete full body, including coding/browsing poses in row2 (their boots are missing in Image1; restore full legs and boots). Same anatomical scale and foot baseline in all frames, consistent laptop between paired frames. No labels or gridlines. Cells order unchanged: row1 idle open eyes, idle closed eyes, thinking, waiting; row2 codingA, codingB, browsingA, browsingB; row3 walkingA, walkingB, climbingA, climbingB; row4 celebratingA, celebratingB, concernedA, concernedB. This is a functional CSS animation atlas and spacing is essential. Transparent alpha in all gutters. Prefer 2048x2048 pixels.

## Integration

Tool output is 1254 x 1254 RGBA. Generated positions are not a perfectly even grid; measured per-pose source rectangles are used at render time. The original PNG is not modified. All nine activities are implemented, but the six two-frame loops are early animation assets rather than a smooth multi-frame character rig.
